A single one-line excuse, written by a program that outputs exactly one line of text.

## Design note

The joke is told in the agent's own voice, to its human, seconds after the
incident: it confesses and clears itself in the same breath. What makes it
read as a machine is the alibi it reaches for — no ticket number, no
dashboard, just an apology and a server running warmer than it should, the
sort of clue only something living on the hardware would notice. The twist
sits in the final clause, nothing is wasted, and at 129 characters the line
leaves the limit alone.
